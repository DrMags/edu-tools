QTI Quiz Tool

A Claude skill that turns your own course sources into quiz and exam packages that import into Canvas Classic Quizzes and Blackboard Ultra question banks. Claude asks about your goals, drafts the questions for your review, and packages them only after you approve.

Each build gives you an importable .zip, an answer-key review sheet, a spec file for revising the quiz later, and a short list of things to check after import.

Download qti-quiz-tool.zip

Set it up in Claude

  1. In Claude, make sure code execution and file creation is turned on.
  2. Go to Customize > Skills. Some versions label this Settings > Capabilities.
  3. Choose the option to upload a skill, and upload the .zip file as downloaded. Do not unzip it first.
  4. Start a new chat and ask Claude to build a quiz. Have your objectives, readings, or notes ready to upload.

Skill availability depends on your Claude plan. On Enterprise plans, an administrator may need to turn skills on. Current details are in the Claude Help Center article Using skills in Claude.

What it can do

  • Works in any discipline, starting from the sources you provide.
  • Offers a wide range of Canvas question types, including formula questions with randomized values.
  • Checks alt text, answer-format instructions, and color contrast for accessibility.
  • Stops a build when a source appears to contain student names, IDs, or grades.

The skill is built for Claude and relies on scripts Claude runs while packaging, so it is not designed for other AI tools.
